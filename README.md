# nfse-auditor

An auditor folder for NFS-e (Brazilian electronic service invoices) in the national standard: it reads the XML a client issued in a month and checks each note against the national NFS-e layout and the ISS law, reporting pass, fail, cannot-determine and not-applicable per check, with the provision cited from `reference/`.

**State of this repository.** This is the first commit: the request for round 0 and the round protocol (`rounds/`), written before any auditor file existed. The auditor's files — `identity.md`, `rules.md`, `examples.md`, `reference/` — enter in later commits, after the round-0 request, so that the order in which things were built can be checked in the history.

**Built for** Weekly Comp #12, "The Auditor"; submission deadline Friday 2026-09-11, 23:59 EST. This README is rewritten when the folder is usable; the version you are reading stays in the history.

**How this was built, in the open.** `rounds/round-0-by-hand/REQUEST.md` is the office's own conversation with the author on the day the work started, published with the participants' agreement (`rounds/CONSENT.md`), people replaced by roles.
