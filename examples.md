# examples.md — worked audits, exactly as the auditor returned them

These are real runs of this folder in a Claude project, on the fixtures in `fixtures/` (anonymised notes of the author's own company, issued by the office), kept **verbatim** — nothing was corrected after the run. Each example says what was fed and in what conditions; the expected result of each run, written before the run, is in `expected/` (outside the loaded set). Each Portuguese report is followed by an English twin. **In examples 1 to 4b the English was produced by the auditor itself**, in the same conversation, on the request "Please repeat the report above in English" — the test being whether it looks the English quotes up in `reference/en/` instead of translating them. It did in examples 1, 3 (on the second answer, after leaving the Portuguese in on the first — kept) and 4b, and the checker confirms every English quote as a verbatim substring of `reference/en/`. **From example 5 on the English is a rendering by the author's session**, not an answer of the auditor: the quotes are looked up in `reference/en/` the same way and checked by the same tool; the Portuguese is the original. Asking the auditor again would have cost the operator a run each time and proved nothing new. What each run showed and what changed in the folder after it, with the commit, is listed in `rounds/fixture-runs-v1/what-changed.md`. **Three of the runs are here** — a correct note, a note with one field altered, and the null case — because that is what an example file is for. **All the runs, in order, including the wrong answers kept as they came, are in `rounds/fixture-runs-v1/report-all-runs.md`**; the numbering here follows that order, which is why the examples below are 1, 3 and 4b.

> **Format note, 10/09/2026.** The examples below were run before `rules.md` § 3 changed after round 1 (check cell carrying its label; severity cell carrying who acts; short location; CSV block at the end). They are kept exactly as they came, so their tables show the earlier shape. The rules govern; the first run in the revised shape is added here as soon as it happens.
