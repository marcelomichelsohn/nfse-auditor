# Fixture runs of v1 (09/09/2026) — what each run showed, and what changed in the folder because of it

The author ran the folder on its own fixtures in a Claude project (conditions in `examples.md`, per example). Predictions were committed before each run (`expected/`, commit 760eaa0 and later); the reports are in `examples.md` exactly as returned. This file is the single list, in order, of what a run showed and what was changed after it — each change in its own commit, the report never edited. For the rounds with the office, the same list lives in `round-N-*/what-changed.md`.

Also found while loading the project, before any run (not from a report): a Claude project refuses `.zip` and reads `.xlsx` poorly → the official annexes shipped as CSV, the XSD unpacked (3ea3db4); the project flattens paths, so `pt/excerpts/x.txt` and `en/excerpts/x.txt` collided → English excerpts renamed `*.en.txt` (074accd); the placeholder README of the first commit says the folder is not usable yet, so it was not loaded for these runs (the README that replaces it is written after the examples).

**What these runs do not prove.** They were fed by the author, on anonymised notes of the author's own company, with the profile line the author wrote. They show what the folder returns on inputs whose answer was written down first; they do not show a person from the office using it — that is what the rounds in `round-*/` are for.
