# Round 0 — the request, the protocol and the documents that exist (08/09/2026)

**What this is.** The WhatsApp exchange of one day in the office's group, verbatim, in Portuguese, people replaced by the roles of `../README.md` § Roles; nothing else edited. It is the first record of this repository: the product did not exist when it was written. Publishing it was asked and agreed the same day — `../CONSENT.md`.

**Part 1 (10:33–12:35) — the request and the protocol.** Marcelo asks the office to record round 0: the Employee doing this month's closing of one client by hand, no system, narrating. The Manager chooses **Marcelo's own company** ("uma empresa que roda tudo certinho"); a second, error-bearing client only if one appears at this month's closing, and only after the office's confidentiality agreement for third-party companies. Marcelo's 12:30 message is the round protocol, formalised in `../PROTOCOL.md`.

**Part 2 (12:40–16:14) — which documents exist.** Marcelo asks for an XML of a note his own company issued. The office sends the municipality's text export instead: that municipality does not generate XML and does not send to the national portal. The Employee names the office's pain (14:19): the fiscal software downloads both the national-portal XML and the municipality's file, but analyses only the national one, and municipalities do not integrate in time. Marcelo states what this folder is and is not (15:33): it will not solve that pain; it is a seed and a test of working together. Consequence for the rounds: v1 reads only national-standard XML, so round 1 runs on the office's own notes, not on the notes of round 0 (`../PROTOCOL.md` point 4).

**Plan B for round 0.** If no recording arrives by Thursday 10/09 morning, round 0 becomes the Manager's written report of 07/09 (her times for the process), labelled *report, not recording*; a later recording replaces it and `../README.md` records the swap with the date.
